# Support

PFOS is in active pre-release development. Here is where each kind of help
lives:

| Need | Where |
| --- | --- |
| Bug report | [Issue tracker](https://github.com/Siddhesh-ai-del/pfos/issues) with the [bug template](https://github.com/Siddhesh-ai-del/pfos/issues/new?template=bug_report.yml) |
| Feature idea | [Feature request template](https://github.com/Siddhesh-ai-del/pfos/issues/new?template=feature_request.yml) |
| Question or idea discussion | [Discussions](https://github.com/Siddhesh-ai-del/pfos/discussions) |
| Security report | [Private security advisory](https://github.com/Siddhesh-ai-del/pfos/security/advisories/new) — never a public issue |

There is **no support SLA at this stage**. The maintainer triages reports
best-effort between build milestones; issues that trace a bug with exact
inputs and outputs get attention first.

Expected first response: acknowledged within a few days, triaged within a
week or two, fixed as part of the relevant development slice.
