# T1 Brief — Competitor landscape (global + India)

Research the current (2025–2026) landscape of personal expense-tracking / budgeting apps.

Find and compare:

1. **Global aggregators**: Mint (→ Credit Karma shutdown), Copilot Money, Monarch Money, YNAB, Wallet by BudgetBakers, Spendee, Emma, Rocket Money.
2. **India-specific players**: Walnut, Money Manager (Realbyte), ET Money, Fi Money, Jupiter, CRED, Jar, Axio (formerly Capital Float/Walnut parent?), Easy Split/Zoho Expense-adjacent tools. Note which are still active (Walnut reportedly shut down operations), which are bank-sync based, and whether any support manual NL-style entry.
3. **Consumption/subscription trackers**: any app that tracks "how many meals did I consume" style metered consumption (e.g., gym/streak apps, Gullak-style)? This is a differentiator for tiffin tracking.
4. **LLM-native or agentic finance apps** (2024–2026): any product marketing itself as an "AI money assistant" (e.g., Cleo Fin, Fella/other ADHD-money apps, Persona AI, Period's "AI CFO" demos, Y Combinator money-agent startups).

For each notable app capture: **capture method** (bank sync / OCR / manual form / chat), **memory model** (transactions only? decisions? commitments/recurring?), **budget monitoring**, **reports**, **India fit (UPI, ₹, tiffin-style consumption)**, **assistant/agentic behavior**, and **pricing**.

## Deliverable

Write findings to `outputs/.drafts/pfos-research-competitors.md` as a markdown table + short gap analysis. Compare against PFOS's five pillars: NL capture, financial memory (transactions/decisions/commitments/consumption), budget monitoring, recurring + consumption tracking, automated reports. List what NO existing app does well — that's our gap.

Rules:
- Use websearch + webfetch. Prefer official sites, product pages, app store listings, TechCrunch/YC profiles for status.
- Record the exact URL next to each claim. No invented features — if unsure about an app's status, mark it "unverified".
- Aim ≤ 8 distinct searches. Prefer skimming product pages over long reads.
- Include a 5-row "gap table" at the end: gap → which competitors fail it → how PFOS addresses it.
